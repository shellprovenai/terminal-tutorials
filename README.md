# Terminal tutorials, tested

Commands and demo setups from the [ShellProven](https://www.youtube.com/@ShellProven) YouTube channel.
Every command shown in a video was executed in a fresh Debian 13 container; outputs in each README are real.
Run `setup.sh` in a scratch folder (or a throwaway container) to recreate the demo, then follow the README.

> Scripts and narration are made with the help of AI and reviewed by a human. Found a mistake? Open an issue.
